## [1.0.0] - 2026-03-24

### Added
- **Spring Boot Backend**: Full-featured REST API using Spring Boot 3.x
- **Gemini AI Integration**: Google Gemini AI model integration via Spring AI
- **React Frontend**: Modern frontend application built with React 18 and Vite
- **Chat Functionality**: Real-time chat interface with AI-powered responses
- **CORS Configuration**: Cross-Origin Resource Sharing support for frontend-backend communication
- **OpenAPI Documentation**: REST API documentation using SpringDoc OpenAPI
- **Exception Handling**: Global exception handling with custom error responses
- **Docker Support**: Containerization with Docker and Docker Compose
- **Unit Tests**: Comprehensive unit tests for controller and service layers
- **Environment Configuration**: Environment-based configuration with example property files
